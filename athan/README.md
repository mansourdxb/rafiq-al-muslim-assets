# athan media

Background media for the athan (call-to-prayer) screen of the رفيق المسلم (Rafiq Al-Muslim) app.
Served from `https://raw.githubusercontent.com/mansourdxb/rafiq-al-muslim-assets/main/athan/...`

`athan/v1/manifest.json` lists the packs. Each pack = a folder of portrait (9:16) images or
silent H.264 MP4 loops plus `thumb.jpg`.
