# King Fahd Complex QCF V1 page fonts (Madinah mushaf, 1405)

`p1.ttf` … `p604.ttf` — one font per mushaf page, used by Rafiq Al-Muslim's المصحف to draw each page
with the printed King Fahd glyphs.

- Source: King Fahd Glorious Quran Printing Complex (KFGQPC) QCF V1 fonts, as distributed by
  quran.com (`https://verses.quran.foundation/fonts/quran/hafs/v1/ttf/p{page}.ttf`), retrieved 2026-10-16.
- Files are byte-identical to the source. The app verifies every download against the SHA-256 list in
  `client/data/mushaf/qcf-v1-fonts.json` (app repo) and refuses any file that differs.
- Do not edit, rename, re-encode or optimise these files.
